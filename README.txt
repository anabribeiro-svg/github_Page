CÓDIGO CRIATIVO — PORTFÓLIO

ARQUIVOS
- index.html: conteúdo do site
- style.css: cores, fontes, layout e adaptação para celular
- script.js: menu mobile e animações

COMO PUBLICAR NO GITHUB PAGES (PELO CELULAR)
1. Baixe e extraia o arquivo ZIP.
2. Abra seu repositório no GitHub.
3. Toque em Add file (Adicionar arquivo) e depois em Upload files (Enviar arquivos).
4. Envie index.html, style.css e script.js para a raiz do repositório (não envie apenas a pasta ZIP).
5. Toque em Commit changes.
6. Abra Settings > Pages.
7. Em Build and deployment, selecione Deploy from a branch.
8. Escolha a branch main e a pasta /(root), depois toque em Save.
9. Aguarde alguns minutos e abra o endereço que o GitHub Pages mostrar.

OBSERVAÇÕES
- O Bootstrap e as fontes são carregados pela internet; mantenha conexão para ver o visual completo.
- Os links dos projetos apontam para o GitHub geral e podem ser substituídos pelos links de cada repositório.
- A ilustração da página inicial é feita em CSS, então não depende de uma imagem externa.
- Para personalizar textos, abra index.html e edite o trecho desejado.
